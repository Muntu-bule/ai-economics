# Post 09 — Scoreboard #3: The Returns Gap

**Question:** How much of the AI value banks claim is actually reported?
**Headline result:** 1,107 AI use cases disclosed across the top 50 banks since 2021; only 12 of 50 report any realised or projected AI value; only 12% disclose an operational-KPI effect and ~1% a concrete financial return.
